# Smart Wallet

تطبيق أندرويد عربي لاختصارات خدمات فودافون كاش.

## الإصدار الأول

- واجهة عربية من اليمين إلى اليسار.
- إدخال رقم المستلم والمبلغ مع تحقق مبدئي من البيانات.
- مراجعة البيانات قبل الانتقال إلى خدمة فودافون.
- فتح شاشة الاتصال على الكود الرسمي `*9*7#` باستخدام `ACTION_DIAL`.
- لا يطلب التطبيق الرقم السري ولا يخزنه ولا ينفذ الاتصال أو التحويل تلقائيًا.
- يختار المستخدم شريحة فودافون بنفسه من شاشة الاتصال إذا عرض الهاتف اختيار الشريحة.

**مهم:** بعد فتح قائمة فودافون، أدخل رقم المستلم والمبلغ والرقم السري بنفسك، وراجع كل التفاصيل قبل تأكيد العملية. البيانات التي كتبتها في التطبيق لا تُمرر تلقائيًا إلى قائمة USSD.

## بناء APK

كل دفع إلى فرع `main` يشغّل GitHub Actions لبناء نسخة Debug. ويمكن تشغيل البناء يدويًا من تبويب **Actions** عبر **Build Smart Wallet APK**.

بعد نجاح البناء:
1. افتح تشغيل workflow الأحدث.
2. انزل إلى **Artifacts**.
3. نزّل `Smart-Wallet-debug`.
4. فك ضغط الملف لتحصل على `app-debug.apk`.

المشروع يستخدم Android Gradle Plugin 8.7.3 وGradle 8.9 وJDK 17 في بيئة البناء السحابية. لا يحتاج الكمبيوتر الذي يعمل بنظام Windows 7 إلى تثبيت Android Studio.

## ملاحظات

- الحد الأدنى المدعوم Android 6.0 (API 23)، ويشمل Android 14.
- هذه نسخة أولية للاختبار وليست تطبيقًا رسميًا تابعًا لفودافون.
- لا يحتوي التطبيق على تكامل مصرفي أو وصول إلى رصيد المحفظة.
